# 📦 出貨照片資料庫 (Export Photo Database)

![Version](https://img.shields.io/badge/version-1.9.7-blue.svg)
![Status](https://img.shields.io/badge/status-stable-green.svg)

本系統專為出貨流程中的照片管理設計，整合了 IndexedDB 本地資料庫與 PWA 技術，確保在各種環境下都能高效記錄與查詢。

## 📖 操作使用手冊 (User Manual)

### 1. 核心流程
*   **進入系統**：預設進入「資料庫」，可快速搜尋歷史記錄。
*   **建立新案**：點擊右上角 **📸** 圖示開始新的拍照流程。
*   **拍照與備註**：選擇對應的**模板 (Template)**，系統會根據模板自動載入拍照項目。
*   **編輯修正**：
    *   **快速編輯**：在詳情頁針對單一項目點擊「✏️ 編輯項目」可直接修改。
    *   **全域編輯**：詳情頁右上角 ✏️ 可修改主表資訊。

### 2. 資料庫管理
*   **搜尋**：支援「客戶代碼」與「出貨地」關鍵字查詢。
*   **備份 (💾)**：
    *   點擊此圖示可選擇 **匯出 (Export)** 或 **匯入 (Import)**。
    *   建議每週固定匯出一次 JSON 檔存放在雲端，以防資料遺失。
*   **設定 (⚙️)**：
    *   **模板管理 (Template Management)**：自定義不同的拍照模板，並為每個模板設定專屬項目。
    *   **備份郵件設定**：可設定預設的備份接收信箱。

### 3. 受限裝置資料導出指南 (Restricted Device Guide)
若您的行動裝置受到安全限制（無法安裝 App、無藍芽、無網路硬碟），請依循以下步驟進行備份導出：

1.  在 App 中點擊「💾 備份」，選擇「匯出完整備份」。
2.  系統詢問匯出方式時，選擇 **【確定】(下載檔案)**。
    *   *註：若無法下載，請選擇【取消】(顯示內容)，然後將文字複製出來。*
3.  使用 USB 傳輸線將裝置連接至電腦。
4.  在電腦上開啟檔案總管，進入裝置儲存空間的 `Download` (下載) 資料夾。
5.  找到 `photo_backup_YYYY-MM-DD.json` 檔案。
6.  將檔案複製到電腦，即完成備份。

### 3. 技術點
*   **PWA 支援**：支援離線使用，右下角顯示版本號（目前 v1.9.7）。
*   **自動大寫**：客戶代碼與出貨地自動轉換為英文大寫。
*   **照片檢視**：支援全螢幕放大功能，並在照片上自動生成浮水印。

### 4. 匯出檔檢視與離線讀取
*   **離線檢視工具**：專案內含 `ExportViewer.html`，可在不依賴主程式的情況下讀取匯出的 `.json` 備份檔。
*   **讀取照片**：將備份檔拖入檢視器即可直接瀏覽所有照片與備註。
*   **命名與下載**：
    *   支援**單張下載**與**批次下載**（按筆數或按全案）。
    *   **命名邏輯**：自動設定為 `客戶代碼_出貨地_項目名稱_日期_序號.jpg`。
*   **批次下載教學**：建議在瀏覽器設定中關閉「下載前先詢問儲存位置」，即可達成一鍵快速存入指定資料夾。

## 📥 安裝與部署
1. 推送代碼至 GitHub 會自動透過 GitHub Pages 部署。
2. 手機開啟網址後，點選瀏覽器選單中的「加入主畫面」即可完成 App 化安裝。

## 🛠 技術棧
*   Frontend: Vanilla JS, CSS3, HTML5
*   Storage: IndexedDB (Database), LocalStorage (Settings)
*   PWA: Service Worker, Manifest.json
